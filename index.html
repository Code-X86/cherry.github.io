Why Cherry

Built to stay simple.

Not Python. Not Rust. Not a wrapper. Cherry has its own lexer, parser, runtime, package manager, and execution engine — written from scratch.

{ }

Cleaner parsing

Brace-based blocks and a deterministic grammar. No whitespace sensitivity, no surprises.

⚡

Rust-powered core

The interpreter and toolchain are written in Rust, and Cherry now requires a local Rust toolchain to run normal commands.

📦

Native packages

Packages ship compiled Rust modules as .chy archives — SHA256-verified on install.

▶

Quick scripting

Write a .ch file and run it immediately. No build step, no boilerplate, no config required.

🔐

Verified installs

Every native binary target includes a SHA256 hash. Cherry rejects mismatched packages before execution.

🧪

Experimental by design

Cherry is a hobby language built for learning, prototyping, and AI-assisted language development.

Syntax

Familiar, but cleaner.

Cherry feels like Python to write but uses braces for blocks and has no indentation rules.

let name = "Cherry"
let mut count = 0

fn main() {
    while count < 3 {
        print("Hello from " + name)
        count = count + 1
    }
}

Language goals

Simple enough for beginners, useful enough for real hobby projects, and flexible enough to grow into a larger ecosystem.

How it's built

Developed with GPT-5.5 assistance for iteration speed, with manual debugging, refactoring, and optimizations by the project owner.

Getting started

Install and run.

Cherry ships as a Linux ELF, and it requires Rust with rustc and cargo available locally.

# Make executable
chmod +x cherry

# Add to PATH
./cherry bootstrap

# Run a script
cherry run main.ch

# Check environment
cherry doctor

Rust requirement

Rust is required to use Cherry. Cherry checks for rustc and cargo before running scripts, checking files, building projects, or installing packages.

CLI commands

cherry runExecute a .ch file
cherry checkParse without running
cherry installInstall a .chy package
cherry newScaffold a project
cherry doctorCheck environment
