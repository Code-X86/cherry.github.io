A simple language with a Rust-powered core.

Cherry is an independent programming language written in Rust. It is designed to feel quick and approachable like Python, while using a cleaner parser, native packages, and its own runtime.

Install Cherry View Example

import mathplus

fn main() {
    let result = mathplus.add(5, 10)
    print(result)
}

Built to stay simple.

Cherry is not Python, Rust, or a wrapper. It has its own lexer, parser, runtime, package manager, and execution engine.

{ }

Cleaner parsing

Cherry uses brace-based blocks and a simpler grammar to avoid slow, complicated, whitespace-sensitive parsing.

⚡

Rust-powered runtime

The Cherry executable is written in Rust, but Cherry programs are executed by Cherry's own runtime.

📦

Native packages

Packages can include Rust-built native modules while remaining easy to import and use from Cherry code.

▶

Quick scripts

Cherry is made for fast scripting, small tools, experiments, and simple programs that are easy to run.

🔐

SHA256 verification

Native package targets can include hashes so Cherry can verify binaries before installation.

🧪

Experimental by design

Cherry is a hobby language built for learning, testing language ideas, and AI-assisted development.

Python-like speed. Cleaner structure.

Cherry keeps the syntax small and readable while avoiding Python compatibility problems.

Language goals

Cherry aims to be simple enough for beginners, useful enough for real hobby projects, and flexible enough to grow into a larger ecosystem.


It is mainly developed with GPT-5.5 assistance, with manual fixes, debugging, refactoring, and optimizations by the project owner.

Native `.chy` packages.

Cherry packages are compressed archives containing metadata and native Rust modules compiled for specific platforms.


mathplus.chy ├── Ident.toml ├── README.md └── bin/ └── linux-x86_64/ └── libmathplus.so
[[targets]]
os = "linux"
arch = "x86_64"
file = "bin/linux-x86_64/libmathplus.so"
sha256 = "..."

[api.add]
args = ["int", "int"]
returns = "int"

Install and run.

Cherry is currently distributed as a standalone Linux ELF executable.

chmod +x cherry
./cherry

# Add Cherry to PATH
./cherry bootstrap

# Run a script
cherry run main.ch

Rust requirement

Rust is not required to run Cherry programs or use existing packages.


Rust is required only when building native `.chy` packages.


rustc --version
cargo --version
